# シレン2 ダメージ計算機 要求仕様書

## 1. 目的

本ツールは『風来のシレン2 鬼襲来！シレン城！』における通常攻撃ダメージを確認するための計算機である。

既存の先駆者サイト「KOYUBI Pages シレン2 ダメージ計算」と同等の入力項目・表示内容・使い勝手を目指す。

ただし、内部のダメージ計算式については、ユーザーが過去に調査した正確な計算式を採用する。

## 2. 基本方針

### 2.1 先駆者サイトと同等にする部分

以下は先駆者サイトと同等の内容を目指す。

- 受ダメ表示
- 与ダメ表示
- 倒確率n表示
- レベル入力
- 武器入力
- 力入力
- 武器印入力
- その他攻撃力条件
- 盾入力
- 盾印入力
- 階層による絞り込み
- モンスター名の部分一致検索

### 2.2 本ツール独自にする部分

以下は本ツール独自仕様とする。

- ダメージ計算式
- 整数化のタイミング
- 乱数補正の扱い
- ダメージ分布の詳細表示
- 実測データとの比較機能
- 計算根拠の確認用表示

### 2.3 重要な前提

本ツールは、KOYUBI Pages のシレン2ダメージ計算と同等の入力項目・表示内容を目指すが、計算結果は本リポジトリで定義する正確式を正とする。

そのため、表示項目や操作性は先駆者サイトに寄せるが、計算結果が先駆者サイトと異なる場合は、本ツール側の正確式による結果を優先する。

## 3. 対象範囲

### 3.1 対象とするダメージ

初期実装では、通常攻撃のダメージを対象とする。

対象:

- 敵からシレンが通常攻撃を受けた場合の受ダメ
- シレンが敵へ通常攻撃した場合の与ダメ
- 敵HP満タンから通常攻撃をn回行った場合の倒確率

### 3.2 後続対応とするもの

以下は初期実装では必須としない。

- 投擲ダメージ
- 杖・巻物・罠によるダメージ
- 爆風ダメージ
- 固定ダメージ
- 特殊な敵能力による補正
- 状態異常による補正
- 連続攻撃や複数回攻撃の特殊処理

## 5. 出力仕様

### 5.1 モンスター一覧

絞り込み条件に一致するモンスターを一覧表示する。

表示列は以下を基本とする。

| 列 | 内容 |
|---|---|
| 名前 | モンスター名 |
| HP | モンスターHP |
| 攻撃力 | モンスター攻撃力 |
| 防御力 | モンスター防御力 |
| 受ダメ | 敵から通常攻撃を受けたときの最小〜最大ダメージ |
| 与ダメ | 敵に通常攻撃したときの最小〜最大ダメージ |
| 倒確率 | 敵HP満タンからn回通常攻撃したときの撃破確率 |

### 5.2 受ダメ

受ダメは、敵の攻撃力とシレン側の防御条件から計算する。

表示形式:

```text
最小ダメージ ～ 最大ダメージ
```

詳細表示では、必要に応じて以下も表示する。

- 64通りのダメージ一覧
- ダメージごとの出現回数
- ダメージごとの確率
- 計算に使用した敵攻撃力
- 計算に使用したシレン側防御力

### 5.3 与ダメ

与ダメは、シレン側の攻撃条件と敵の防御力から計算する。

表示形式:

```text
最小ダメージ ～ 最大ダメージ
```

詳細表示では、必要に応じて以下も表示する。

- 64通りのダメージ一覧
- ダメージごとの出現回数
- ダメージごとの確率
- 計算に使用したシレン側攻撃力
- 計算に使用した敵防御力
- 武器印や会心などの補正適用結果

### 5.4 倒確率

倒確率は、敵HP満タンから通常攻撃をn回行った場合に、敵を倒せる確率を表示する。

表示形式:

```text
n回攻撃時の撃破確率: xx.xx%
```

#### 5.4.1 倒確率の基本方針

1回攻撃のダメージ分布を作成し、n回攻撃時の合計ダメージ分布を畳み込みで計算する。

```text
damage_distribution = {
  ダメージ値: 出現通り数
}
```

n回攻撃時に合計ダメージが敵HP以上となる確率を倒確率とする。

```text
倒確率 = 合計ダメージ >= 敵HP となる通り数 / 全通り数
```

1回攻撃の乱数が64通りであれば、n回攻撃の全通り数は以下となる。

```text
64 ^ n
```

#### 5.4.2 倒確率nの扱い

先駆者サイトと同等に、倒確率nは「敵HP満タンからn回通常攻撃したときに倒せる確率」とする。

nの範囲や表示個数は、既存UIの見やすさを考慮して決める。

初期実装では、以下を目安とする。

- 1回
- 2回
- 3回
- 4回
- 5回

必要に応じて、nを入力可能にする。

## 6. 計算仕様

### 6.1 計算式の基本方針

本ツールでは、先駆者サイトの表示内容を参考にするが、内部の計算式はユーザーが過去に調査した正確な式を使用する。

仕様上、以下の2段階を明確に分ける。

```text
1. 攻撃力・防御力・補正条件から、基準ダメージを求める
2. 乱数補正を適用して、最終ダメージ分布を求める
```

### 6.2 正確式

正確式は、過去の調査結果に基づいて以下の関数として実装する。

```text
calculateBaseDamage(attacker_attack, defender_defense, options)
```

入力:

| 引数 | 内容 |
|---|---|
| attacker_attack | 攻撃側の攻撃力 |
| defender_defense | 防御側の防御力 |
| options | 会心、特効、印などの補正条件 |

出力:

| 戻り値 | 内容 |
|---|---|
| base_damage | 乱数補正前、または乱数補正に渡す内部基準値 |

現時点の仮仕様としては、以下の考え方を扱えるようにする。

```text
base_damage = attacker_attack に対して defender_defense 分の減衰を適用した値
```

守備力減衰の調査式が以下である場合:

```text
base = attacker_attack

defender_defense 回だけ以下を繰り返す。
base = floor(base * 35 / 36)
```

または、固定小数点方式である場合:

```text
内部値を256倍固定小数点などで保持し、
防御力補正・乱数補正の後にゲーム内部と同じタイミングで整数化する。
```

この部分は、ユーザーが以前調査した正確な式で確定する。

### 6.3 乱数補正

最終ダメージは、基準ダメージに乱数補正を適用して求める。

乱数補正値は以下の64通りとする。

```text
224, 225, 226, ..., 287
```

各乱数値 `r` に対して、最終ダメージを求める。

```text
damage = floor(base_damage * r / 256)
```

ただし、正確式で乱数補正前後の整数化タイミングが異なる場合は、正確式を優先する。

### 6.4 会心の一撃

会心の一撃を有効にした場合、与ダメ計算に会心補正を適用する。

仕様上は以下の関数に分離する。

```text
applyCriticalModifier(base_damage, options)
```

補正倍率・整数化タイミングは、調査済み仕様または既存コードの仕様確認後に確定する。

### 6.5 特効武器印

武器印による特効は、対象モンスターの系統と一致する場合に攻撃側補正として適用する。

対応する印:

- 成仏のカマ
- ドレインバスター
- 一ツ目殺し
- 月三日刀
- ドラゴンキラー
- 龍神剣

仕様上は以下の関数に分離する。

```text
applyWeaponSealModifiers(attack, monster_traits, selected_seals)
```

特効倍率・適用順・整数化タイミングは、調査済み仕様または既存コードの仕様確認後に確定する。

### 6.6 ちから・武器・印の攻撃力反映

シレン側の攻撃力は、以下の要素から算出する。

- レベル
- 武器の攻撃力
- 現在ちから
- 武器印
- その他攻撃力条件

加算順・乗算順・整数化タイミングは、調査済み仕様または既存コードの仕様確認後に確定する。

仕様上は以下の関数に分離する。

```text
calculatePlayerAttack(level, weapon, strength, selected_weapon_seals, attack_options)
```

### 6.7 盾・盾印の防御力反映

シレン側の防御力は、以下の要素から算出する。

- 盾の防御力
- 盾印
- その他防御条件

加算順・乗算順・整数化タイミングは、調査済み仕様または既存コードの仕様確認後に確定する。

仕様上は以下の関数に分離する。

```text
calculatePlayerDefense(shield, selected_shield_seals, defense_options)
```

## 9. テスト仕様

### 9.1 単体テスト対象

以下の関数を単体テスト対象とする。

```text
calculateBaseDamage
calculateDamageDistribution
calculateDamageRange
calculateKillProbability
applyWeaponSealModifiers
applyShieldSealModifiers
calculatePlayerAttack
calculatePlayerDefense
filterMonsters
```

### 9.2 最低限の検証ケース

| ケース | 内容 |
|---|---|
| 防御力0 | 防御力補正なしで計算できること |
| 攻撃力0 | ダメージ0または最小保証の扱いを確認すること |
| 低攻撃・低防御 | 通常ケース |
| 高攻撃・高防御 | 高防御時の減衰確認 |
| 会心あり | 会心補正が適用されること |
| 特効あり | 対象系統にのみ特効補正が適用されること |
| 名前検索 | 部分一致で絞り込めること |
| 最果てへの道 | 階層条件で絞り込めること |

### 9.3 回帰テスト

ユーザーが過去に実測したケースを回帰テストとして固定する。

例:

```text
攻撃力22 / 防御力6
攻撃力200 / 防御力53
```

期待値は、過去調査済みの正確式に基づく結果を使用する。

### 9.4 受ダメ・与ダメの対称性確認

同じ攻撃力・防御力を使った場合、受ダメ計算と与ダメ計算は同じ基礎計算関数を通ることを確認する。

ただし、シレン側とモンスター側で補正要素が異なる場合は、それぞれの補正適用後の値を比較対象とする。

```text
- KOYUBI Pages のシレン2ダメージ計算と同等の入力・表示を目指す
- ただし、内部の計算式は別途定義する正確式に差し替える

確認してほしいこと:
1. レベル、武器、力、武器印、盾、盾印の入力がどこで管理されているか
2. モンスターデータがどこにあるか
3. 受ダメを計算している関数
4. 与ダメを計算している関数
5. 倒確率を計算している関数
6. UIと計算ロジックが分離されているか
```

### 10.2 第2段階: 仕様書追加

```text
docs/shiren2_damage_calculator_spec.md を追加してください。

内容は、KOYUBI Pages のシレン2ダメージ計算と同等の入力・表示を目指すこと、
ただし計算式は本リポジトリで定義する正確式を使うことを明記してください。
```

### 10.3 第3段階: 計算ロジック分離


## 12. 実装時の注意

- 先駆者サイトと同等の入力・表示を目指すが、計算式は本仕様書で定義する正確式を優先する。
- UI変更と計算式変更は、可能な限り別コミット・別Pull Requestに分ける。
- 計算ロジックには、後から意図が追いやすいようコメントを多めに付ける。
- 受ダメと与ダメで同じ基礎計算ロジックを使えるようにする。
- 正確式が未確定の箇所には、仮実装であることをコメントに残す。
- 仕様書にない補正をCodexが独自判断で追加しないよう、変更範囲を明示する。
