# シレン2 ダメージ計算機 要求仕様書

## 1. 目的

本ツールは、風来のシレン2における通常攻撃ダメージを確認するための計算機です。

主な目的は、ゲーム中に次の判断を素早く行えるようにすることです。

- シレンが敵を何発で倒せるか
- n発攻撃したときの撃破率
- 敵の通常攻撃を受けたときに現在HPで耐えられるか
- 1発被弾に対する安全/危険/死亡の簡易判定

## 2. 対象範囲

初期実装の対象は、命中した通常攻撃です。

対象:

- シレンから敵への通常攻撃による与ダメージ
- 敵からシレンへの通常攻撃による被ダメージ
- 1回攻撃分布を元にした撃破率

対象外:

- ミス、回避
- 固定ダメージ
- 投擲、罠、爆風
- 特殊攻撃
- 複数回攻撃の特殊処理
- 状態異常による補正

## 3. 正確式の基本方針

攻撃力と防御力が確定した後のダメージ分布は、VBA版 `DamageDist_Build` と同じ方式を正確式とします。

旧仕様または仮式として検討していた `224〜287/256` の64通り乱数補正は、現在の正確式ではありません。
仕様書、テスト、実装で正とする分布は、`widthQ16` ベースの分布です。

## 4. 共通分布生成

与ダメ、被ダメ、撃破率は、同じ1回攻撃分布生成関数を使います。

```text
calculateDamageDistribution(attack, defense)
```

この関数は次の手順で分布を作ります。

```text
avgQ16 = ApplyDefense_Q16(attack, defense)
widthQ16 = avgQ16 >> 3

for m = 0..widthQ16:
  dmgQ16 = avgQ16 - m
  dmg = dmgQ16 >> 16
  if dmg == 0:
    dmg = 1
  count[dmg] += 1

  dmgQ16 = avgQ16 + m
  dmg = dmgQ16 >> 16
  if dmg == 0:
    dmg = 1
  count[dmg] += 1

totalOutcomes = 2 * (widthQ16 + 1)
prob = count[dmg] / totalOutcomes
```

`totalOutcomes` は64固定ではなく、入力値によって変化します。

## 5. 防御減衰

防御減衰は `ApplyDefense_Q16` 相当の処理で行います。

```text
Q16 = 65536
a0Q16 = attack * Q16
d = defense

for i = 0..8:
  if d == 0:
    break

  if (d & 1) != 0:
    a0Int = a0Q16 >> 16
    a0Q16 = a0Int * table[i]

  d = d >> 1

avgQ16 = a0Q16
```

係数テーブル:

```text
[63716, 61946, 58552, 52312, 41757, 26606, 10801, 1780, 48]
```

防御係数を掛ける直前に `a0Q16 >> 16` で整数化する点を正とします。

## 6. 与ダメージ

与ダメージでは、次の値を共通分布生成へ渡します。

```text
attack = シレン側の攻撃力
defense = 敵側の防御力
```

シレン側の攻撃力は、レベル、武器の強さ、ちからから算出します。
武器印、会心などの補正は、対応済みの仕様から順に反映します。

## 7. 被ダメージ

被ダメージでは、次の値を共通分布生成へ渡します。

```text
attack = 敵側の攻撃力
defense = シレン側の防御力
```

敵側の攻撃力は、モンスターデータまたは直接入力の値を使います。
シレン側の防御力は、盾の強さと盾印から算出します。

## 8. 撃破率

撃破率は、`calculateDamageDistribution(attack, defense)` が返す1回攻撃分布を畳み込んで求めます。

別の分布、64通り固定の分布、`224〜287/256` の旧仕様分布は使用しません。

```text
1回攻撃分布 = calculateDamageDistribution(attack, defense)
n回攻撃分布 = 1回攻撃分布をn回畳み込み
撃破率 = 合計ダメージ >= 敵HP となる確率
```

標準表示では、1〜6発の撃破率を表示します。

## 9. tail 確率

詳細分布では、VBA版と同じ考え方で tail 確率を扱います。

| 値 | 内容 |
|---|---|
| `tailProbGte` | `P(damage >= row.damage)` |
| `tailProbGt` | `P(damage > row.damage)` |

表示では、必要に応じて `tail(>=)` を確認できるようにします。

## 10. 安全/危険/死亡判定

被ダメージ分布の最小値と最大値、現在HPから1発被弾に対する簡易判定を行います。

```text
if hp <= minTaken:
  死亡
else if hp <= maxTaken:
  危険
else:
  安全
```

この判定は1発被弾に対する簡易判定です。
自動回復や複数ターンの行動順は含めません。

## 11. モンスターデータ

モンスターデータは `モンスターデータ.csv` から読み込みます。

基本列:

```text
モンスター名, HP, 攻撃, 守備, 種1, 種2
```

モンスター選択時は、HP、攻撃力、守備力をフォームへ反映します。
ただし、ユーザーが手動で上書きできることを優先し、候補にないモンスターでも直接入力で計算できるようにします。

## 12. 表示項目

### 与ダメージ

- 与ダメージ最小〜最大
- 最短撃破回数
- 確定撃破回数
- 1〜6発の撃破率
- 与ダメージ分布

### 被ダメージ

- 被ダメージ最小〜最大
- 現在HPで何発耐えられるか
- 最大被ダメージ基準で何発耐えられるか
- 最小被ダメージ基準で何発耐えられるか
- 被ダメージ分布

### 判定サマリー

- 安全/危険/死亡
- 現在HP
- 被ダメージ最小〜最大
- 最大被ダメージでも1発耐えるか
- 次の一撃で死亡ありか

## 13. 旧仕様の扱い

次の仕様は、旧仕様または仮式として扱います。

- 64通り固定のダメージ分布
- `224〜287/256` の乱数補正
- `totalOutcomes = 64`
- `64 ^ n` を母数とする撃破率

現在の正確式では、総通り数は常に次で求めます。

```text
totalOutcomes = 2 * (widthQ16 + 1)
```
