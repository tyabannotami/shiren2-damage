# シレン2 通常攻撃ダメージ計算式

## 目的

この文書は、シレン2ダメージ計算機で使用する通常攻撃ダメージ計算式を明文化するものです。

現在の正確式では、旧仕様として検討していた `224〜287/256` の64通り乱数補正は使用しません。
ダメージ分布は、VBA版 `DamageDist_Build` と同じ `widthQ16` ベースの分布生成を正とします。

## 対象範囲

対象は、命中した通常攻撃1回ぶんのダメージ分布です。

この文書では、攻撃側の攻撃力と防御側の防御力がすでに数値として確定している前提で、そこから1回攻撃のダメージ分布を求める部分を定義します。

プレイヤーのレベル、武器、ちから、印、盾、補正条件などから攻撃力・防御力そのものを算出する処理は、この文書の直接の対象外です。

## 1. 防御減衰後の平均値を求める

入力値を次のように置きます。

| 名前 | 内容 |
|---|---|
| `attack` | 攻撃側の攻撃力 |
| `defense` | 防御側の防御力 |
| `avgQ16` | 防御減衰後の平均値。Q16固定小数点 |

防御補正は、単純に `35/36` を `defense` 回掛ける式ではありません。

次の式は、考え方を説明するための仮式・近似式としてのみ扱います。実装では使用しません。

```text
base_damage = attack

defense 回だけ繰り返す:
  base_damage = floor(base_damage * 35 / 36)
```

実装で使用する正確式は、Q16固定小数点と防御力の2進数ビット分解を使う `ApplyDefense_Q16` 相当の処理です。

```text
Q16 = 65536

table[i] = round((35 / 36) ^ (2 ^ i) * Q16)
  i = 0..8

a0Q16 = attack * Q16
d = defense

for i = 0..8:
  if d == 0:
    break

  if (d & 1) != 0:
    a0Int = a0Q16 \ Q16
    a0Q16 = a0Int * table[i]

  d = d \ 2

avgQ16 = a0Q16
```

重要な点は、防御係数を掛ける前に必ず `a0Q16 \ 65536` で整数化することです。
整数化した `a0Int` にQ16係数 `table[i]` を掛け、割らずにQ16のまま保持します。

防御力が0の場合、防御補正は適用せず、`avgQ16 = attack * 65536` とします。

係数テーブルは次の値を使用します。

| `i` | 対応する防御力ビット | 係数式 | 10進 | 16進 |
|---:|---:|---|---:|---:|
| 0 | 1 | `round((35/36)^1 * 65536)` | 63716 | `0xF8E4` |
| 1 | 2 | `round((35/36)^2 * 65536)` | 61946 | `0xF1FA` |
| 2 | 4 | `round((35/36)^4 * 65536)` | 58552 | `0xE4B8` |
| 3 | 8 | `round((35/36)^8 * 65536)` | 52312 | `0xCC58` |
| 4 | 16 | `round((35/36)^16 * 65536)` | 41757 | `0xA31D` |
| 5 | 32 | `round((35/36)^32 * 65536)` | 26606 | `0x67EE` |
| 6 | 64 | `round((35/36)^64 * 65536)` | 10801 | `0x2A31` |
| 7 | 128 | `round((35/36)^128 * 65536)` | 1780 | `0x06F4` |
| 8 | 256 | `round((35/36)^256 * 65536)` | 48 | `0x0030` |

## 2. 分布幅を求める

`ApplyDefense_Q16` で求めた `avgQ16` から、VBA版と同じ分布幅を求めます。

```text
widthQ16 = avgQ16 >> 3
```

`>> 3` は整数除算 `avgQ16 \ 8` と同じ意味です。

## 3. VBA版 DamageDist_Build 相当の分布生成

ダメージ分布は、`m = 0..widthQ16` を両端含みで走査し、各 `m` について `-側` と `+側` を両方カウントします。

```text
for m = 0..widthQ16:
  dmgQ16 = avgQ16 - m
  dmg = dmgQ16 >> 16
  if dmg == 0:
    dmg = 1
  count[dmg] += 1

  dmgQ16 = avgQ16 + m
  dmg = dmgQ16 >> 16
  if dmg == 0:
    dmg = 1
  count[dmg] += 1
```

`>> 16` は整数除算 `dmgQ16 \ 65536` と同じ意味です。

総通り数は次の通りです。

```text
totalOutcomes = 2 * (widthQ16 + 1)
```

各ダメージ値の確率は次の通りです。

```text
prob = count[damage] / totalOutcomes
percent = prob * 100
```

この方式では、`totalOutcomes` は入力値によって変わります。
`64` 固定ではありません。

## 4. 最小ダメージ保証

VBA版と同じく、`dmg = 0` の場合だけ `1` に補正します。

```text
if dmg == 0:
  dmg = 1
```

したがって、命中した通常攻撃の表示・分布・撃破率計算に使う1回ぶんのダメージは必ず1以上です。

表示上の1ダメージには、内部的な `dmg = 0` と `dmg = 1` が集約される場合があります。

## 5. tail 確率

詳細分布では、VBA版と同じ考え方で tail 確率を扱います。

```text
tail(>=damage) = damage 以上を引く確率
tail(>damage)  = damage より大きい値を引く確率
```

Web実装では、行ごとに次の値を持たせます。

| 名前 | 内容 |
|---|---|
| `tailProbGte` | `P(damage >= row.damage)` |
| `tailProbGt` | `P(damage > row.damage)` |

## 6. 旧仕様 224〜287/256 の扱い

`224〜287/256` を64通り列挙する方式は、旧仕様または仮式として扱います。

現在の正確式では使用しません。
仕様書、テスト設計、実装で「正確式」として扱う分布は、`DamageDist_Build` 相当の `widthQ16` ベース分布です。

## 7. 与ダメ・被ダメ・撃破率で共通化する部分

与ダメと被ダメは、攻撃力・防御力の作り方が異なるだけで、攻撃力と防御力が確定したあとの分布生成は共通です。

共通化する処理は次の範囲です。

```text
calculateDamageDistribution(attack, defense)
```

この共通処理の責務は次の通りです。

1. `attack` と `defense` から `ApplyDefense_Q16` で `avgQ16` を求める。
2. `widthQ16 = avgQ16 >> 3` を求める。
3. `m = 0..widthQ16` の `-側` と `+側` を両方カウントする。
4. `dmg = dmgQ16 >> 16` で整数化する。
5. `dmg = 0` の場合は1を保証する。
6. `totalOutcomes = 2 * (widthQ16 + 1)` を母数として確率を求める。
7. `tailProbGte` と `tailProbGt` を求める。

与ダメでは、シレン側の攻撃条件から作った攻撃力と、敵側の防御力をこの共通処理へ渡します。

```text
attack = シレン側の攻撃力
defense = 敵側の防御力
```

被ダメでは、敵側の攻撃力と、シレン側の防御条件から作った防御力をこの共通処理へ渡します。

```text
attack = 敵側の攻撃力
defense = シレン側の防御力
```

撃破率は、同じ `calculateDamageDistribution(attack, defense)` が返す1回攻撃分布を畳み込んで求めます。
別の乱数分布や64通り固定の分布は使用しません。

## 8. 確定方針と対象外

この文書で確定する主対象は、攻撃力・防御力が確定した後の通常攻撃ダメージ分布です。

### 8.1 攻撃力の算出順

シレン側の攻撃力は、レベル、武器、ちからについては現行の処理通りに算出します。

武器印、会心などの補正は、その後に適用します。

### 8.2 防御力の算出順

シレン側の防御力は、盾の強さをもとに算出します。

盾印による強さ補正は、防御力計算前に盾の強さへ加算します。

```text
shield_power = 盾の強さ + 盾印による強さ補正
defense = floor(shield_power / 2)
```

シレン2にはその他防御印を考慮する必要がないため、通常攻撃ダメージ計算では扱いません。

### 8.3 特効・会心などの補正

特効、会心、状態異常、複数回攻撃などの補正は、今後の個別仕様に従います。

### 8.4 防御力512以上

`ApplyDefense_Q16` 相当処理は `i = 0..8` の係数テーブルを使います。

防御力512以上はゲーム上到達不可能のため、上位ビットの追加対応は不要とします。

### 8.5 通常攻撃以外のダメージ

ミス、回避、特殊攻撃、固定ダメージ、投擲、罠、爆風など、通常攻撃以外のダメージ計算は今回は実装しません。

## 参考式まとめ

```text
Q16 = 65536
table = [63716, 61946, 58552, 52312, 41757, 26606, 10801, 1780, 48]

a0Q16 = attack * Q16
d = defense

for i = 0..8:
  if d == 0:
    break

  if (d & 1) != 0:
    a0Int = a0Q16 >> 16
    a0Q16 = a0Int * table[i]

  d = d >> 1

avgQ16 = a0Q16
widthQ16 = avgQ16 >> 3

for m = 0..widthQ16:
  dmgQ16 = avgQ16 - m
  dmg = dmgQ16 >> 16
  if dmg == 0:
    dmg = 1
  count[dmg] += 1

  dmgQ16 = avgQ16 + m
  dmg = dmgQ16 >> 16
  if dmg == 0:
    dmg = 1
  count[dmg] += 1

totalOutcomes = 2 * (widthQ16 + 1)
prob = count[dmg] / totalOutcomes
```
