# シレン2 通常攻撃ダメージ計算式

## 目的

この文書は、シレン2ダメージ計算機で使用する通常攻撃ダメージ計算式を、実装前の正仕様として明文化するものです。

後続の計算ロジック修正では、この文書に記載した式と整数化タイミングを正とします。

## 対象範囲

対象は、命中した通常攻撃1回ぶんのダメージです。

この文書では、攻撃側の攻撃力と防御側の防御力がすでに数値として確定している前提で、そこから最終ダメージを求める部分を定義します。

プレイヤーのレベル、武器、ちから、印、盾、補正条件などから攻撃力・防御力そのものを算出する処理は、この文書の直接の対象外です。

## 1. 攻撃力と防御力から基準ダメージを求める手順

入力値を次のように置きます。

| 名前 | 内容 |
|---|---|
| `attack` | 攻撃側の攻撃力 |
| `defense` | 防御側の防御力 |
| `base_damage_q16` | 防御減衰後、乱数補正前の基準ダメージ。Q16固定小数点 |

防御補正は、単純に `35/36` を `defense` 回掛ける式ではありません。

次の式は、考え方を説明するための仮式・近似式としてのみ扱います。実装では使用しません。

```text
base_damage = attack

defense 回だけ繰り返す:
  base_damage = floor(base_damage * 35 / 36)
```

実装で使用する正確式は、Q16固定小数点と防御力の2進数ビット分解を使う `ApplyDefense_Q16` 相当の処理です。

```text
Q16 = 65536

table[i] = round((35 / 36) ^ (2 ^ i) * Q16)
  i = 0..8

a0Q16 = attack * Q16
d = defense

for i = 0..8:
  if d == 0:
    break

  if (d & 1) != 0:
    a0Int = a0Q16 \ Q16
    a0Q16 = a0Int * table[i]

  d = d \ 2

base_damage_q16 = a0Q16
```

重要な点は、防御係数を掛ける前に必ず `a0Q16 \ 65536` で整数化することです。整数化した `a0Int` にQ16係数 `table[i]` を掛け、割らずにQ16のまま保持します。

防御力が0の場合、防御補正は適用せず、`base_damage_q16 = attack * 65536` とします。

係数テーブルは次の値を使用します。

| `i` | 対応する防御力ビット | 係数式 | 10進 | 16進 |
|---:|---:|---|---:|---:|
| 0 | 1 | `round((35/36)^1 * 65536)` | 63716 | `0xF8E4` |
| 1 | 2 | `round((35/36)^2 * 65536)` | 61946 | `0xF1FA` |
| 2 | 4 | `round((35/36)^4 * 65536)` | 58552 | `0xE4B8` |
| 3 | 8 | `round((35/36)^8 * 65536)` | 52312 | `0xCC58` |
| 4 | 16 | `round((35/36)^16 * 65536)` | 41757 | `0xA31D` |
| 5 | 32 | `round((35/36)^32 * 65536)` | 26606 | `0x67EE` |
| 6 | 64 | `round((35/36)^64 * 65536)` | 10801 | `0x2A31` |
| 7 | 128 | `round((35/36)^128 * 65536)` | 1780 | `0x06F4` |
| 8 | 256 | `round((35/36)^256 * 65536)` | 48 | `0x0030` |

## 2. 整数化のタイミング

整数化は次のタイミングで行います。

1. 防御補正で対象ビットの係数を掛ける直前に、`a0Int = a0Q16 \ 65536` で整数化します。
2. `a0Q16 = a0Int * table[i]` とし、割らずにQ16固定小数点のまま保持します。
3. 乱数補正を適用したあと、Q16を整数ダメージに戻すときに切り捨てます。
4. 最小ダメージ保証は、乱数補正後の整数化が終わったあとに適用します。

防御補正では、`attack * (35 / 36) ^ defense` を一括計算して最後に切り捨てるのではありません。また、`35/36` を防御力の回数だけ逐次的に掛ける式も正確式ではありません。

## 3. 乱数補正 224〜287/256 の扱い

通常攻撃1回の乱数補正は、次の64通りです。

```text
224, 225, 226, ..., 287
```

各乱数値 `random` は等確率で発生するものとして扱います。

各 `random` に対して、乱数補正後のダメージを次の式で求めます。

```text
damage_before_minimum = floor(base_damage_q16 * random / (256 * 65536))
```

補正倍率として見ると、最小は `224 / 256 = 0.875`、最大は `287 / 256 = 1.12109375` です。

ダメージ分布を作る場合は、64通りすべての `final_damage` を計算し、同じダメージ値を集約して通り数と確率を求めます。

```text
count[final_damage] += 1
probability = count[final_damage] / 64
```

## 4. 最終ダメージの丸め方

最終ダメージは、乱数補正後に小数部を切り捨てます。

```text
damage_before_minimum = floor(base_damage_q16 * random / (256 * 65536))
```

四捨五入、切り上げ、最近接整数丸めは使用しません。

## 5. 最小ダメージ保証の有無

命中した通常攻撃の最終ダメージには、最小ダメージ1を保証します。

乱数補正後の整数ダメージが1未満になった場合、最終ダメージは1です。

```text
final_damage = max(1, damage_before_minimum)
```

したがって、通常攻撃が命中した場合、表示・分布・撃破確率計算に使う1回ぶんのダメージは必ず1以上です。

## 6. 与ダメと受ダメで共通化できる部分

与ダメと受ダメは、攻撃力・防御力の作り方が異なるだけで、攻撃力と防御力が確定したあとの基礎計算は共通化できます。

共通化できる処理は次の範囲です。

```text
calculateNormalAttackDamageDistribution(attack, defense)
```

この共通処理の責務は次の通りです。

1. `attack` と `defense` から `base_damage_q16` を求める。
2. 防御減衰後の値はQ16固定小数点として保持する。
3. 64通りの乱数補正 `224..287` を適用する。
4. 乱数補正後に `floor` で整数化する。
5. 最小ダメージ1を保証する。
6. 同じ最終ダメージを集約して分布を返す。

与ダメでは、シレン側の攻撃条件から作った攻撃力と、敵側の防御力をこの共通処理へ渡します。

```text
attack = シレン側の攻撃力
defense = 敵側の防御力
```

受ダメでは、敵側の攻撃力と、シレン側の防御条件から作った防御力をこの共通処理へ渡します。

```text
attack = 敵側の攻撃力
defense = シレン側の防御力
```

## 7. 確定方針と対象外

この文書で確定する主対象は、攻撃力・防御力が確定した後の通常攻撃ダメージ計算です。周辺仕様については、現時点で次の方針とします。

### 7.1 攻撃力の算出順

シレン側の攻撃力は、レベル、武器、ちからについては現行の処理通りに算出します。

武器印、会心などの補正は、その後に適用します。

### 7.2 防御力の算出順

シレン側の防御力は、盾の強さをもとに算出します。

盾印による強さ補正は、防御力計算前に盾の強さへ加算します。

```text
shield_power = 盾の強さ + 盾印による強さ補正
defense = floor(shield_power / 2)
```

シレン2にはその他防御印を考慮する必要がないため、通常攻撃ダメージ計算では扱いません。

### 7.3 特効・会心などの補正

特効、会心、状態異常、複数回攻撃などの補正は、基準ダメージ計算後に適用します。

ここでいう基準ダメージ計算後とは、攻撃力と防御力から `base_damage_q16` を求めた後を指します。

### 7.4 範囲外の値

攻撃力や防御力が通常プレイで取りうる範囲外の値になった場合でも、基本的には計算を行います。

ただし、運用上の問題が出る場合はエラーとして扱い、「範囲外」として表示し、計算結果は表示しません。

### 7.5 防御力512以上

`ApplyDefense_Q16` 相当処理は `i = 0..8` の係数テーブルを使います。

防御力512以上はゲーム上到達不可能のため、上位ビットの追加対応は不要とします。

### 7.6 通常攻撃以外のダメージ

ミス、回避、特殊攻撃、固定ダメージ、投擲、罠、爆風など、通常攻撃以外のダメージ計算は今回は実装しません。

ただし、今後、敵モンスターの特技による固定ダメージなどを追加する可能性があります。

### 7.7 詳細分布の表示

表示上の最小〜最大ダメージに加えて、詳細分布を表示します。

## 参考式まとめ

```text
Q16 = 65536
table = [63716, 61946, 58552, 52312, 41757, 26606, 10801, 1780, 48]

a0Q16 = attack * Q16
d = defense

for i = 0..8:
  if d == 0:
    break

  if (d & 1) != 0:
    a0Int = a0Q16 \ Q16
    a0Q16 = a0Int * table[i]

  d = d \ 2

for random in 224..287:
  damage_before_minimum = floor(a0Q16 * random / (256 * Q16))
  final_damage = max(1, damage_before_minimum)
```
